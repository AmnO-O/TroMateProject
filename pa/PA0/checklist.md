# PA0 – Group Registration & Tools Setup — Checklist

**Course:** Elements of Software Engineering — 24A01
**Total score:** 30 points
**Type:** Teamwork assignment
**Deadline (all parts):** 11/10/2026

---

## 1. Group Registration

- [ ] Form groups of **3–5 students** each.
- [ ] Fill in the registration form using the provided **Google Sheet** (link in the assignment).
- [ ] Specify the **group name**.
- [ ] Specify the **group leader** (the **first person** listed on the form = group leader).
- [ ] For **each member** provide:
  - [ ] Student ID
  - [ ] Full name
  - [ ] Email address
- [ ] Submit the Google Sheet before **11/10/2026**.

---

## 2. Project Proposal

- [ ] Discuss the project idea within the group.
- [ ] Ensure the project fits the scope: **not too large** (>50 screens/functions) and **not too small** (<6 screens/functions).
- [ ] (Recommended) Focus on a **mobile or Web application**.
- [ ] (Preferred) Include interesting features addressing **real user needs** or applying **AI** (generative AI, agentic AI).
- [ ] Write a project description containing:
  - [ ] **Team members**
  - [ ] **Introduction** — briefly describe the idea and why it is worthy to do
  - [ ] **Target users and environments** — who the users are and the environments used (devices, OS, Web, etc.)
  - [ ] **Key features** — list the key features of the app
- [ ] Conduct interviews with **at least 5 potential users/customers** to confirm or discover new ideas.
- [ ] Include **evidence of the interviews**:
  - [ ] Audio/video recording of the interviews
  - [ ] Notes taken
  - [ ] Information about the interviewers (background, occupation, interests, other characteristics)
- [ ] (Optional) Talk to the instructor or TAs for suggestions/feedback.
- [ ] Ensure TAs review and **approve** the proposal (or apply suggested changes).
- [ ] Submit before **11/10/2026**.

---

## 3. Tools Setup

> Tools are used to monitor/assess teamwork performance. Effective use is an important grading criterion — everyone must use them regularly.

- [ ] **Moodle** — for posting and submitting assignments.
- [ ] **Facebook group** — for general notifications, class discussions, Q&A (includes both classes).
  - [ ] Join the group.
  - [ ] If NOT using Facebook, inform the instructor so an alternative notification method can be arranged.
- [ ] **Slack** (or MS Teams / Discord) — for group discussions and interactions.
  - [ ] TAs create the Slack project and add all students.
  - [ ] Use the **general channel** for general project discussions.
  - [ ] Use the **group channel** (linked to Trello) for project discussion.
  - [ ] Install/open the desktop and mobile apps and check frequently.
- [ ] **JIRA** (or Azure Boards) — each group has **one board**.
  - [ ] Organize tasks into **sprints**.
- [ ] **Bitbucket / GitHub / other source control** — store source code and documentation.
  - [ ] Ensure the group belongs to a **team** on the repository.
  - [ ] Create the following folders:
    - [ ] `/src` — source code
    - [ ] `/docs` — documentation, with subfolders:
      - [ ] `management` — planning documents, reports (weekly report, project status report, etc.)
      - [ ] `requirements` — all requirements (vision document, use cases)
      - [ ] `analysis and design` — analysis/design docs (software architecture document, UML models, UI design)
      - [ ] `test` — test documents (test plan, test cases, test reports)
    - [ ] `/pa` — submissions; each subfolder contains one PA submission
- [ ] Attend the first lab sessions where TAs help set up these tools.
